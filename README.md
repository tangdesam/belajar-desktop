## Install Firefox

Run the installer from the repository root:

```bash
bash scripts/install-firefox.sh
```

The latest Firefox release is downloaded from Mozilla and installed to:

```text
~/apps/firefox/firefox
```

The script requires `curl`, `tar`, and an x86_64 Linux environment.
